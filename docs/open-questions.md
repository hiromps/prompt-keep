# Open Questions

- **目的**: 未決事項を「決めるべきこと」として管理し、暗黙の前提で実装が進むのを防ぐ。
- **対象読者**: 開発者本人・AIアシスタント（実装前にここを確認し、勝手に決めない）。
- **記入方法**: 疑問が出たら追加。決まったら「決定」に移し、必要なら ADR / 該当 docs に反映して行を消す。
