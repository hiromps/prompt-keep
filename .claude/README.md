# .claude — プロジェクト固有の AI 拡張置き場

| ディレクトリ | 用途 |
|---|---|
| `skills/` | プロジェクト固有スキル（定型作業の手順書）。`skills/<name>/SKILL.md` の形式 |
| `agents/` | カスタムサブエージェント定義（`<name>.md` + frontmatter） |
| `settings.json` | 権限・フック等のプロジェクト設定 |

ルールは `../CLAUDE.md` に集約している。ここには「毎回は不要だが、特定作業で呼び出す手順」だけを置く。

スキル追加の目安: 同じ複合作業（例: 新機能の feature 一式生成、migration + 型生成 + queries の雛形化）を3回以上繰り返したらスキル化する。
